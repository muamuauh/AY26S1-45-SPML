> 文档版本：v1.0 ｜ 生成日期：2026-08-18
> 英文对照版：[02-Datasets-and-Pretrained-Models-EN.md](02-Datasets-and-Pretrained-Models-EN.md)
> 用途：为 TelecomSafe 的 M1（数据基建）与 M3（感知模型）提供选型依据

---

## ⚠️ 首要结论

**目前不存在公开的、电信施工场景专用的安全检测数据集。**

这既是本项目的核心困难，也正是立项理由（项目简介所说的 `limited availability and diversity of labelled, sector-specific images`）。

因此数据策略必须是三段式：

```
公开通用建筑数据集（迁移基座，量大）
        ↓
电信场景真实种子数据（自采，量小但关键 → 用于 LoRA 微调 + 测试集）
        ↓
生成式合成数据（本项目创新，规模化补齐长尾）
```

**测试集必须 100% 使用真实的电信场景图像**，否则所有实验结论都不可信。这一点务必在 M1 就固化。

## 一、施工安全通用数据集

### 1.1 综合场景检测

| 数据集 | 规模 | 类别 | 特点 | 对本项目的价值 |
|--------|------|------|------|--------------|
| **SODA** (Site Object Detection dAtaset) | 19,846 张 / 286,201 个目标 | 15 类，覆盖 worker / material / machine / layout 四组 | 多视角（远景 42.8%、近景 34.7%、塔吊钩视角 15.5%、UAV 7.0%）；YOLOv3/v4 基线 mAP 达 81.47% | ⭐⭐⭐⭐⭐ **首选迁移基座**。类别分组与本项目四维度高度吻合 |
| **MOCS** (Moving Objects in Construction Sites) | 41,668 张 | 13 类，**像素级**标注 | 规模最大；含低空 UAV 视角；无俯视图 | ⭐⭐⭐⭐ 适合 Machinery 分支与实例分割预训练 |
| **ACID** (Alberta Construction Image Dataset) | 10,000 张 | 10 类施工机械 | 地面视角，机械类别专注 | ⭐⭐⭐⭐ Machinery 分支专用 |
| **AIDCON** | 航拍图像 | 施工机械 | **UAV 航拍专用基准** | ⭐⭐⭐ 若做 UAV 输入则必备 |

> SODA 论文：Duan, R., Deng, H., Tian, M., Deng, Y., Lin, J. (2022). *SODA: A large-scale open site object detection dataset for deep learning in construction*. Automation in Construction. arXiv:2202.09554

### 1.2 PPE / 安全帽专项

| 数据集 | 规模 | 类别 | 特点 | 价值 |
|--------|------|------|------|------|
| **CHV** (Color Helmet and Vest) | 1,330 张 | 多类 PPE（安全帽颜色 + 反光背心） | 真实工地背景，多姿态、多角度、多距离；公开可用 | ⭐⭐⭐⭐⭐ Workers 分支起步首选 |
| **SHEL5K** | 5,000 张扩展标注 | 6 类（头/戴帽头/未戴帽头/人/安全帽/人脸） | Safety Helmet Detection 数据集的扩展加强版，标注质量高 | ⭐⭐⭐⭐⭐ 标注最完善的 PPE 集 |
| **SHWD** (Safety Helmet Wearing Dataset) | 约 7,581 张 | 2 类（hat / person） | 使用最广泛的中文社区基准 | ⭐⭐⭐⭐ 量大易得，类别偏少 |
| **Pictor-v3** | 约 1,500 张 | worker / hat / vest 组合状态 | 含众包与网络图像 | ⭐⭐⭐ 组合状态标注思路值得借鉴 |
| **CHVG / 大规模安全服装数据集** | 万级 | 安全服 + 安全帽 | 场景复杂真实 | ⭐⭐⭐ 补充多样性 |

### 1.3 不安全行为 / 视频动作

| 资源 | 说明 | 价值 |
|------|------|------|
| **Construction Action Recognition (GitHub: S1mpleyang)** | 配套 Automation in Construction 论文的施工不安全动作视频数据集与代码 | ⭐⭐⭐⭐⭐ 行为分支**唯一直接可用**的公开资源，务必优先获取 |
| **CMAR / 施工工人动作数据集** | 施工动作分类 | ⭐⭐⭐ |
| **NTU RGB+D 60/120** | 通用人体动作骨架数据集 | ⭐⭐⭐⭐ ST-GCN 预训练基座，迁移效果好 |
| **Kinetics-400/700** | 通用视频动作 | ⭐⭐⭐⭐ VideoMAE 等模型预训练权重来源 |

> 参考论文：Yang, M., Wu, C., Guo, Y., Jiang, R., Zhou, F., Zhang, J., Yang, Z. (2023). *Transformer-based deep learning model and video dataset for unsafe action identification in construction projects*. Automation in Construction, 146, 104703.

### 1.4 地形 / 地面条件

**⚠️ 没有直接可用的公开数据集。** 这是四个维度中数据最匮乏的一环。

**可行的替代路线**：

| 路线 | 做法 | 成本 |
|------|------|------|
| A. 从 SODA/MOCS 二次标注 | 对现有图像的地面区域重新做 5 类分割标注 | 中（约 300–500 张即可训练轻量分割头） |
| B. SAM 2 自动分割 + 人工归类 | 用 SAM 2 生成地面区域候选，人工只做类别归属 | **低（推荐）**，可省 70% 标注时间 |
| C. 通用场景分割迁移 | ADE20K / Cityscapes 预训练 → 微调 | 低，但类别语义不匹配 |
| D. 生成式合成 | 用 ControlNet-Depth 生成坑洼/沟槽/积水地面 | 中，正是本项目要展示的能力 |

> **建议采用 B + D 组合**：B 提供真实测试集，D 提供训练数据规模化，恰好成为生成式增广有效性的一个漂亮案例。

### 1.5 材料堆放

**同样没有专用公开数据集。** SODA 的 material 组（钢筋、木材、砖块等）是最接近的起点，但"堆放不当"这一**状态判断**需要自行定义与标注。

**建议定义可量化的判据**（避免主观标注争议）：
- 堆放高度 / 底面宽度比 > 阈值 → 倾覆风险
- 是否越出划定区域（需要场地边界标注）
- 是否阻塞通道 / 逃生路径
- 是否有捆扎固定

## 二、生成模型选型

### 2.1 基础文生图模型

| 模型 | 参数量 | 显存需求（推理/LoRA训练） | 图像质量 | 生态成熟度 | 许可 | 推荐度 |
|------|--------|------------------------|---------|-----------|------|--------|
| **SDXL 1.0** | 2.6B | 8GB / 12–16GB | 好 | **极成熟**（ControlNet/LoRA 生态最全） | CreativeML Open RAIL++-M | ⭐⭐⭐⭐⭐ **首选** |
| **Stable Diffusion 3.5 Medium** | 2.5B | 10GB / 16GB | 很好（文字渲染强） | 成熟中 | Stability Community License（研究免费） | ⭐⭐⭐⭐ 备选 |
| **FLUX.1-dev** | 12B | 24GB / 24GB+ | **最好** | 快速成熟中 | Non-commercial（研究可用） | ⭐⭐⭐⭐ 显存够就用 |
| **SD 1.5** | 0.86B | 4GB / 8GB | 一般 | 极成熟 | CreativeML Open RAIL-M | ⭐⭐⭐ 算力受限时的保底 |
| **SDXL-Turbo / LCM** | — | 同 SDXL | 略降 | 成熟 | 同上 | ⭐⭐⭐⭐ **批量生成时用，1–4 步出图，速度提升 10×+** |

> **推荐组合**：**SDXL 1.0 + LoRA + ControlNet**。理由：生态最全（ControlNet 各类条件模型齐备）、显存友好（单张 4090 可训可推）、质量足够、许可清晰。批量生成阶段切换到 SDXL-Turbo 以节省时间。

### 2.2 可控生成组件

| 组件 | 作用 | 在本项目的用法 |
|------|------|--------------|
| **ControlNet-Canny** | 边缘约束 | 保持塔架/机械的结构轮廓，只改变场景与人员 |
| **ControlNet-Depth** | 深度约束 | 控制场地地形起伏、坑槽深度 |
| **ControlNet-OpenPose** | 姿态约束 | **精确生成不安全姿态**（攀爬、探身、蹲踞），这是行为数据合成的关键 |
| **ControlNet-Seg** | 分割图约束 | 🌟 **布局即标注**：先画语义布局图 → 生成图像 → 布局图直接就是分割 GT，标注零成本 |
| **SD Inpainting** | 局部重绘 | 🌟 **PPE 负样本合成**：擦除安全帽/安全带，边界框位置不变，标注可直接复用 |
| **IP-Adapter** | 图像风格参考 | 用少量真实电信照片作为风格锚点，提升领域一致性 |

> **`ControlNet-Seg` 与 `Inpainting` 是本项目性价比最高的两条路线**，因为它们让合成数据"自带标注"，绕开了合成数据最大的成本瓶颈。

### 2.3 领域适配方法对比

| 方法 | 所需数据 | 训练成本 | 过拟合风险 | 推荐 |
|------|---------|---------|-----------|------|
| **LoRA** (rank 16–32) | 200–500 张 | 单卡 1–3 小时 | 低 | ⭐⭐⭐⭐⭐ **首选** |
| DreamBooth | 20–50 张 | 单卡 1–2 小时 | 高 | ⭐⭐⭐ 适合单一目标（如某型号铁塔） |
| Textual Inversion | 5–20 张 | 30 分钟 | 中 | ⭐⭐⭐ 轻量补充，可与 LoRA 叠加 |
| 全量微调 | 5000+ 张 | 数十 GPU 小时 | 中 | ⭐ 数据与算力都不足，不推荐 |

## 三、感知模型选型

### 3.1 目标检测

| 模型 | mAP (COCO) | 速度 | 易用性 | 推荐场景 |
|------|-----------|------|--------|---------|
| **YOLOv11-m/l** | 51.5 / 53.4 | 极快 | ⭐⭐⭐⭐⭐（Ultralytics 一行训练） | ⭐⭐⭐⭐⭐ **主力检测器**，工程落地首选 |
| **RT-DETRv2-L** | 53.4 | 快 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ 无需 NMS，密集小目标更稳 |
| **Co-DETR / DINO** | 60+ | 慢 | ⭐⭐⭐ | ⭐⭐⭐ 若追求 SOTA 精度指标 |
| **Grounding DINO** | 52.5（zero-shot） | 中 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ **预标注神器**，开放词表零样本检测，M1 阶段必用 |

> **建议策略**：主线用 **YOLOv11**（快速迭代、易复现）；论文中补一组 **RT-DETRv2** 结果证明方法与主干无关（method-agnostic），说服力更强。

### 3.2 分割

| 模型 | 用途 | 推荐度 |
|------|------|--------|
| **SAM 2** | 交互式/自动分割，预标注 | ⭐⭐⭐⭐⭐ 标注加速利器 |
| **SegFormer-B0/B2** | 语义分割（地形） | ⭐⭐⭐⭐⭐ 轻量高效，ADE20K 预训练可用 |
| **Mask2Former** | 全景/实例分割 | ⭐⭐⭐⭐ 精度更高但更重 |
| **YOLOv11-seg** | 实例分割 | ⭐⭐⭐⭐ 与检测统一框架，工程省事 |

### 3.3 姿态与行为

| 模型 | 用途 | 推荐度 |
|------|------|--------|
| **YOLOv11-pose** | 2D 人体关键点 | ⭐⭐⭐⭐⭐ 与检测同框架，17 关键点足够 |
| **RTMPose** | 高精度关键点 | ⭐⭐⭐⭐ 精度更高 |
| **ST-GCN++ / CTR-GCN** | 骨架动作识别 | ⭐⭐⭐⭐⭐ **抗低分辨率、抗光照变化，工地场景首选** |
| **VideoMAE V2** | RGB 视频动作识别 | ⭐⭐⭐⭐ 精度高但需要更多视频数据 |
| **X3D / SlowFast** | 轻量视频动作 | ⭐⭐⭐ 传统可靠基线 |

> **强烈建议行为分支走骨架流（YOLOv11-pose → ST-GCN++）**：工地摄像头分辨率低、光照差、人体常远小，骨架表示对这些退化远比 RGB 鲁棒；且骨架数据可由 ControlNet-OpenPose 直接合成，与本项目生成式主线天然契合。

### 3.4 视觉语言模型（可选增强）

| 模型 | 用途 | 推荐度 |
|------|------|--------|
| **Qwen2.5-VL** | 隐患描述生成、开放式风险问答 | ⭐⭐⭐⭐ 开源、中文好、可本地部署 |
| **InternVL 2.5** | 同上 | ⭐⭐⭐⭐ |
| **GPT-4o / Claude** | 提示词工程、生成数据的语义校验 | ⭐⭐⭐⭐ API 便捷，适合做质量闸门的语义审核 |
| **CLIP (ViT-L/14)** | 合成图像语义一致性打分 | ⭐⭐⭐⭐⭐ **质量闸门必备组件** |

## 四、许可证与合规提示

| 类别 | 注意事项 |
|------|---------|
| 数据集 | SODA/MOCS/ACID 多为学术研究用途，**商用需另行申请**；论文中务必注明来源与许可 |
| SDXL | CreativeML Open RAIL++-M，研究与多数商用可用，但禁止生成违法/侵权内容 |
| FLUX.1-dev | **非商用许可**，学术研究可用，若项目有商业化预期需换 FLUX.1-schnell (Apache 2.0) |
| Ultralytics YOLO | **AGPL-3.0**，若不开源则需购买商业许可 —— 校园研究项目通常无碍，但报告中应说明 |
| 自采数据 | 涉及**工人肖像**，需处理隐私：人脸打码 / 获取知情同意 / 仅内部使用 |
| 生成数据 | 合成人物不涉及真人隐私，**这是生成式方案的一个额外优势，值得在论文中强调** |

## 六、数据规模目标

| 数据类别 | 目标规模 | 用途 |
|---------|---------|------|
| 公开通用数据（迁移） | 20,000+ 张 | 主干预训练 / 迁移基座 |
| 电信真实种子数据 | 500–1,000 张 | LoRA 微调 + 真实训练集 |
| **电信真实测试集** | **200–300 张（严格隔离）** | **所有评估的唯一标尺** |
| 生成合成数据 | 3,000–10,000 张 | 增广训练集，长尾补齐 |
| 视频片段（行为） | 200–500 段 | 动作识别训练 |
| 专家风险等级标注 | 200 张 | 融合模块 ground truth |
