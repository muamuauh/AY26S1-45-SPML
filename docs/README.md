## Ground rules of the project

1. **TelecomEval is frozen.** It is never used for training or as input to generation, and the evaluation script refuses to run if its manifest does not match. Any revision is frozen as a new version and all models are re-evaluated.
2. **The baseline configuration is frozen.** `configs/baseline.yaml` does not change after phase 1; E3 changes only the training data.
3. **Real photos are the headline result.** Generated test images are reported separately, because a gain on them can come from learning a generator's style.
4. **Every experiment runs with three seeds** and is reported as mean ± standard deviation.
