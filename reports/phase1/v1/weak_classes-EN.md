# Weak Classes (Phase 2 Generation Targets)

> 中文版：[weak_classes.md](weak_classes.md)

The 4 classes with the lowest E2 AP50 on the validation split. Phase 2's (M3) risk-scenario specification library covers these classes first.

> ⚠️ These are **validation-split** results (TelecomEval is deferred, see progress/milestones-EN.md). The validation split comes from the same sources as training, so the numbers are optimistic;
> re-evaluate the same model once TelecomEval is built before finalising this list.
> The Chinese file is generated by `python -m telecomsafe.evaluate` with the "likely reasons" column filled in by hand; this English version is translated by hand and must be updated alongside it.

| Rank | Class | AP50 | Training instances | Likely reasons (by hand) |
|---|---|---|---|---|
| 1 | vehicle | 0.317 | 261 | One of the smallest classes (only from Construction Site Safety); high intra-class variety (cars, trucks, buses and trailers merged); only 16 validation instances, so AP is noisy |
| 2 | no_helmet | 0.447 | 1057 | Small targets (head only); hard to tell from heads wearing ordinary caps / headscarves; datasets differ in how they box a missing helmet (head box vs person box) |
| 3 | no_vest | 0.774 | 4248 | Defined by an absence rather than a visible object, so torso box boundaries are subjective; mostly from APD, whose style differs from the other sources |
| 4 | machinery | 0.802 | 439 | Few samples (down from 4,820 to 439 after switching to the un-augmented CSS v30); cable-laying vehicles, cable-drum trailers and bucket trucks common in telecom work are almost absent from training |

## Classes that need a special note

- **harness**: AP50 = 0.984 on the validation split, but **not trustworthy**. There are only 143 training instances, all from body_harness; the validation split has just 13 instances, taken from adjacent frames of the same videos as the training images. On the 31 telecom construction candidates (including tower and pole climbing), E2 detected no harness at all. The harness is the most important PPE for telecom work at height and should be phase 2's **first generation target**, alongside the table above.

## Recommendations for phase 2

Generation priority: **harness ≈ vehicle > machinery (telecom-specific vehicles and equipment) > no_helmet > no_vest**. The first three share the problem that public data barely covers them — exactly the scenes generative augmentation is meant to address.
