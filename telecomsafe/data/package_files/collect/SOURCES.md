# 去哪里找、怎么确认许可 / Where to Search and How to Check Licences

## 可以用的网站 / Sites to use

| 网站 Site | 怎么找 How to search | 在哪看许可 Where the licence is |
|---|---|---|
| [Wikimedia Commons](https://commons.wikimedia.org) | 搜索关键词，或浏览分类：{wikimedia_categories} / search, or browse the categories listed | 文件页 "Licensing" 一节 / the "Licensing" section of the file page |
| [Openverse](https://openverse.org) | 搜索后在筛选里只勾选 CC0、Public Domain Mark、CC BY、CC BY-SA / filter to CC0, PDM, CC BY, CC BY-SA | 结果页上的许可，再点进原始来源确认 / shown on the result, confirm on the original source |
| [Flickr](https://www.flickr.com/search/) | 搜索 → "Any license" 改为 "Commercial use & mods allowed" / set the licence filter to "Commercial use & mods allowed" | 照片页右下方的许可图标 / licence icon on the photo page |
| [DVIDS](https://www.dvidshub.net) | 美军媒体库，通信兵（signal）架设天线、光缆的照片很多 / US military media; many signal-unit antenna and cable photos | 默认为公有领域（`US-GOV`）；署名里有 "Courtesy" 或页面写有版权声明的**不收** / public domain (`US-GOV`) unless credited "Courtesy" or marked copyrighted — skip those |
| 美国政府机构的 Flickr 账号 / US agency Flickr accounts | 如 USDA、FEMA、US Army Corps of Engineers 的农村宽带、灾后通信抢修照片 / e.g. USDA, FEMA, USACE: rural broadband, disaster telecom repairs | 许可显示 "United States Government Work" → `US-GOV` |

**不要用 / Do not use**：Google 图片直接下载、Pexels、Unsplash、Pixabay、Getty / Shutterstock / iStock / Alamy 等商业图库、新闻网站、社交媒体、AI 生成图。
Google Images downloads, Pexels, Unsplash, Pixabay, commercial libraries (Getty, Shutterstock, iStock, Alamy...), news sites, social media, AI-generated images.

## 确认许可的要点 / Checking the licence

- 以**来源页面**上写的许可为准，不要以搜索结果页或转载网站为准。
  The licence on the **source page** counts — not a search result or a re-post.
- 看到 **NC**、**ND**、"All rights reserved"、"版权所有" → 不收。
  **NC**, **ND**, "All rights reserved" → leave it out.
- CC-BY / CC-BY-SA 要记下作者名、版本号和许可链接（页面上的许可图标通常链接到许可正文）。
  For CC-BY / CC-BY-SA note the author, version and licence link (the licence badge usually links to it).
- 下载尽量大的尺寸。Wikimedia：点"原始文件"；Flickr：右下角下载按钮选大尺寸。
  Download the largest size. Wikimedia: "Original file"; Flickr: the download button, a large size.
